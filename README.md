# Business Analysis Internship

This repository contains the projects I completed during my Business Analysis internship. The projects cover data analysis, visualization, customer feedback analysis, pricing analysis, and machine learning.

## Projects

### Task 1 - Market Basket Analysis Using Apriori Algorithm
Analyzed customer purchase patterns using the Apriori algorithm to identify frequently purchased products and association rules.

### Task 2 - Retail Price Estimation and Competitive Pricing Analysis
Analyzed retail pricing data to understand pricing patterns and compare recommended prices with competitor prices.

### Task 3 - Customer Feedback Analysis Using Sentiment Analysis
Analyzed customer reviews and classified feedback as positive, neutral, or negative to understand overall customer sentiment.

### Task 4 - Avocado Price Prediction Using Machine Learning
Analyzed historical avocado prices, studied price trends, and applied a Linear Regression model to predict avocado prices.
