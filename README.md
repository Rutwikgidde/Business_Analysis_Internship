# Business Analysis Internship

This repository contains the projects I completed during my Business Analysis internship.

## Projects

### Task 1 - Market Basket Analysis
Analyzed customer purchase patterns using the Apriori algorithm to identify frequently purchased products and association rules.

### Task 2 - Retail Pricing Analysis
Analyzed retail pricing data to identify important pricing patterns and trends.

### Task 3 - Customer Feedback Analysis Using Sentiment Analysis
Analyzed customer reviews and classified feedback as positive, neutral, or negative to understand overall customer sentiment.

### Task 4 - Predicting Avocado Prices
Analyzed historical avocado prices, studied pricing trends, and applied machine learning to predict avocado prices.
